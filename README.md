CHẤM CÔNG PWA - LƯU TRÊN THIẾT BỊ

Dữ liệu tự lưu vào localStorage của trình duyệt sau mỗi thay đổi. Không cần GitHub/token hay mạng để lưu.

SAO LƯU: Vào Cài đặt > Xuất JSON, giữ file backup ở nơi an toàn.
KHÔI PHỤC: Cài đặt > Khôi phục JSON.

LƯU Ý: Xóa dữ liệu trang web, dùng trình duyệt khác, hoặc đổi tên miền có thể khiến dữ liệu cũ không còn xuất hiện. Nên xuất JSON định kỳ.
